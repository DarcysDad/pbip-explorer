PBIP EXPLORER

Explore a Power BI semantic model from its project files

Open a .pbip project folder to browse tables, relationships, measures and DAX lineage, trace report visuals back to source, and audit for broken or unused measures.

Your files never leave your computer. Everything runs in this browser tab. The page has no server, makes no network requests, and its security policy blocks it from sending data anywhere.

Needs a project saved in Power BI Project format with TMDL (File › Save as › Power BI project). Include the .Report folder to map visuals and usage. Folder picking works best in Chrome or Edge; other browsers use a standard folder upload, still processed locally.
